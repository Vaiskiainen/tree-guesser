## Features
- Randomized pictures of finnish trees
- Simple UI 
- Leave & tree images
- Support for finnish and english

## Tech stack
- HTML
- CSS
- JavaScript

## How to play
1. Open [the game](https://treeguesser.vaiskiainen.fi/).
2. Look at the image of the tree.
3. Choose the correct tree from the options.
4. Continue until you have gone through the questions.
